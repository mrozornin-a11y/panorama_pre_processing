# Предварительная обработка панорам петрографических шлифов

Настольная программа (Windows 11, Python 3.13 + PySide6) для подготовки пар панорам
«параллельные / скрещённые николи»: совмещение с **усреднением геометрии**, исправление
локальных расхождений и **общая обрезка**. Результат — пары JPEG одинакового размера с совпадающим
положением деталей, которые открываются в [panorama_marking](https://github.com/mrozornin-a11y/panorama_marking)
как обычная пара. Исходные фотографии не изменяются.

## Установка и запуск

1. Установите Python 3.13 с python.org (отметьте «Add python.exe to PATH»).
2. Дважды щёлкните `run.bat`. При первом запуске создаётся окружение `.venv` и устанавливаются
   зависимости из `requirements.txt` (нужен интернет). Последующие запуски — тем же `run.bat`.

Вручную:

```bat
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

## Работа

1. **Новый проект…** — выберите папку с панорамами (JPG, JPEG, PNG) и место для файла проекта (`.json`).
   Пары определяются как в panorama_marking: `16. Г-170` — параллельные николи, `16. Г-170 с` —
   скрещённые (буква `с`/`c`, кириллическая или латинская, любой регистр). Номер в названии сохраняется.
   Неполные пары отмечены ⚠; исправляются кнопками **Назначить файлы…** и **Поменять местами**.
   **Удалить из списка…** убирает пару из проекта, фотографии на диске не удаляются.
   **Открыть…** — продолжить работу с сохранённым проектом. Проект сохраняется автоматически
   (через 2 с после изменения, при смене пары и при закрытии) и хранит пути, точки, параметры
   совмещения, рамку обрезки и отметки обработки — отдельно для каждой пары.
2. **Точки.** Нажмите **Добавить точки** (для несовмещённой пары режим включён сразу) и ставьте точки
   на одинаковых деталях обеих панорам: щелчок по одной панораме, затем по той же детали на другой.
   Над нужной панорамой и в панели справа подсказано, где ставить следующую точку; пунктирный голубой
   крестик — ожидаемое место (по уже поставленным точкам). Число точек не ограничено; для исправления
   локальных расхождений ставьте 6–12 и больше, равномерно по всей панораме, включая края.
   Точки нумеруются, перетаскиваются мышью, выбираются щелчком или в списке (выбранная пара
   подсвечена жёлтым на обеих панорамах), **Удалить точку** / `Delete` удаляет пару точек.
3. **Усреднить геометрию** — расчёт в фоне. Обе панорамы приводятся к общей промежуточной
   геометрии (вклад 50/50), цвета не смешиваются. При проблеме с точками показывается сообщение с
   номером подозрительной точки. **Показать исходники** — вернуться к исходным изображениям и точкам
   (совмещение и обрезка сохраняются); после правки точек — **Повторить усреднение**: расчёт всегда
   выполняется заново из исходных изображений, деформации не накапливаются.
   **Сбросить совмещение** — убрать совмещение и обрезку (точки остаются).
4. **Просмотр**: **Рядом** (на результате синхронная навигация включается автоматически, на
   исходниках при расстановке точек — независимая), **Наложение** (ползунок прозрачности),
   **Переключение** (`Tab` или кнопка — параллельные ↔ скрещённые в одном окне с сохранением
   положения и увеличения). Режимы работают и для исправленных панорам, и для исходников. В одном
   окне исходники показаны в той же системе координат, что и результат, но только с общим
   смещением, поворотом и масштабом по точкам (без локальной деформации; файлы не меняются) —
   так видно совмещение «до» и «после»: переход между исходниками и результатом также сохраняет
   положение и увеличение. В режиме «Переключение» точки ставятся и перетаскиваются на видимом
   исходнике. Колесо мыши — увеличение и уменьшение: точка под курсором остаётся под курсором;
   средняя кнопка или пробел + левая кнопка — перемещение; **Показать целиком**.
5. **Обрезка.** На результате нарисуйте рамку мышью; её можно двигать и менять за края и углы,
   снаружи область затемнена. Рамка одна для обеих панорам (в общей системе координат).
   Серая «шахматка» — пустые области после деформации: исключите их рамкой.
   **Применить обрезку** (пара отмечается как обработанная), **Сбросить обрезку** — совмещение не
   меняется.
6. **Экспорт текущей** / **Экспорт обработанных** (пары с отметкой «Пара обработана»). Для каждой
   пары в выбранной папке создаётся подпапка с названием пары и два JPEG с исходными базовыми
   именами: `16. Г-170/16. Г-170.jpg` и `16. Г-170/16. Г-170 с.jpg`. Качество JPEG задаётся в панели
   инструментов (90 и выше — без субдискретизации цвета). Если рамки нет, сохраняется весь холст,
   пустые области — белые.

Горячие клавиши: `Ctrl+Z` / `Ctrl+Y` — отмена/повтор (точки, совмещение, обрезка; отдельно для
каждой пары в пределах сеанса), `Delete`, `Esc` (выход из режима добавления точек), `Tab`, `Ctrl+S`.

## Метод

Координаты двух исходников разного разрешения напрямую не усредняются.

1. По всем парам точек методом наименьших квадратов оценивается подобие (смещение, поворот,
   масштаб) «скрещённые → параллельные»: `P ≈ a·Q + b` (комплексная запись).
2. Оно делится пополам: `H(z) = √a·z + b/(1+√a)`, так что `H(H(z))` — всё подобие. Общая система
   координат: `C = H(Q) = H⁻¹(P)` — поворот пополам, масштаб равен среднему геометрическому
   разрешений исходников. В ней точки обеих панорам сопоставимы.
3. Промежуточные положения точек — середины `m = (H⁻¹(P) + H(Q)) / 2`.
4. Остаток (локальные расхождения) — поле смещений **тонкой пластины** (thin-plate spline: аффинная
   часть + радиальные функции r²·log r), точно проходящее через `(H⁻¹(P) − H(Q)) / 2` в точках `m`.
   Параллельные получают `+u`, скрещённые `−u`: каждая панорама исправляется на половину расхождения
   навстречу другой. Тонкая пластина — самая гладкая (минимум энергии изгиба) интерполяция по
   произвольно расположенным точкам; вдали от точек переходит в аффинное преобразование.
   2 точки — только подобие; 3 — аффинное; 4 и больше — плавная деформация.
5. Проверки: не менее 2 полных пар, все точки поставлены на обоих изображениях, точки не совпадают,
   разумный масштаб (0,25–4), не зеркальный порядок; почти на одной прямой — только подобие с
   предупреждением. Складки и перевороты: якобиан обоих отображений проверяется по сетке там, где видно
   изображение; при значении вне 0,2–5 расчёт отклоняется с указанием ближайшей точки.
6. Поле вычисляется в узлах сетки (≈1024 узла по большей стороне холста) и билинейно интерполируется —
   одинаково для предпросмотра и экспорта. Экспорт: одно пересэмплирование (бикубическое) из оригинала
   сразу в обрезанную область, блоками 2048×2048; при уменьшении применяется лёгкое сглаживание
   против муара. DPI не используется.

## Ограничения

- Предпросмотр — до 4096 px по стороне; точки ставятся в координатах исходных файлов.
- Память при экспорте: исходник (≈4 байта/пиксель) + результат (≈4 байта/пиксель), стороны
  обрабатываются по очереди. Пример: исходник 20000×15000 и результат 17800×13800 — около 2,7 ГБ.
- JPEG ограничен 65 500 px по стороне.
- Отмена хранит до 100 действий на пару в пределах сеанса.

## Проверка

`python tests/test_synthetic.py` — синтетическая пара с известными локальными искажениями
(разные разрешение, поворот, смещение и «вздутия» поля на каждой панораме, разные раскраски одной
структуры). Проверяется: изменяются обе панорамы, расхождение деталей в 300 контрольных (не опорных)
точках уменьшается (медиана 7,2 → 0,7 px), корреляция границ растёт (0,59 → 0,97); средние цвета
каждой панорамы сохраняются, раскраски не смешиваются; экспорт совпадает с предпросмотром (сдвиг
< 0,01 px, разница < 1 уровня); общая обрезка даёт одинаковые размеры; сохранение и повторное
открытие проекта восстанавливают поле побитово и дают идентичный экспорт; результат распознаётся
как пара по правилам panorama_marking; ошибочные точки дают понятные сообщения.

`python tests/test_gui.py` — проверка интерфейса без экрана: точка под курсором остаётся на месте
за серию шагов колеса (исходники и результат), синхронная навигация без зацикливания событий,
`Tab` на результате и на исходниках сохраняет увеличение и положение, не меняет точки и совмещение,
точки ставятся на видимом исходнике в его координатах.
